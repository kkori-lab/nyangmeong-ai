# LJS 마일스톤

기준: AI매니저_기능명세서_v0.7_20261009, 마이페이지_기능명세서_v0.4_20261025 (DMS, 2026-10-25)

> **다시 만들어야 함(2026-10-26).** 범위가 기능명세서 v0.9(147건, SCR-AIM-013 추가)로 확정됐고, Python이 DB·JWT를 다루지 않기로 했다(`docs/convention/milestone.md` "범위"·"Python 몫"). v0.9가 DMS에 올라간 뒤 다시 만든다. 그 전에 아래 "끝"인 SCR-AIM-011도 대화 저장을 Java 내부 API로 옮기는 재작업이 남아 있다.

## SCR-AIM-008 영수증 촬영 · 업로드 (OCR 인식·파싱) — 끝
- 기능: FN-AIM-008-06 OCR API 호출, FN-AIM-010-01 인식 실패 · 일시 오류 판정 (화면은 SCR-AIM-010)
- 연결 남음: FN-AIM-008-06 real 모드 (Google Vision 서비스 계정 키, LJS), FN-AIM-008-06·010-01 Java `PythonOcrClient` 연결 확인 (LJS 백엔드)
- Python 전용 DB 계정 불필요(저장하지 않음). 기다리는 것: Google Vision 서비스 계정 키 (LJS, real 모드만), Java `PythonOcrClient` (LJS 백엔드, 연결 확인)
- 완료 조건: mock 모드에서 `POST /internal/v1/ocr/receipt`가 `ReceiptOcrResponse` 모양을 돌려준다. 추출 0건과 오류가 구분되어 응답된다.

## SCR-MYP-010 픽셀 캐릭터 관리 (생성 입력·규격) — 끝
- 기능: FN-MYP-010-08 1단계 · 사진 첨부, FN-MYP-010-17 캐릭터 규격 고정, FN-MYP-010-18 규격 일관성 검증
- 기다리는 것: 이미지 생성 API·키 (팀 결정, real 모드만), Java `PythonCharacterGenerator` (LJS 백엔드, 연결 확인)
- 완료 조건: mock 모드에서 `/internal/v1/character`가 512×512 규격 이미지를 돌려주고, 규격 검증이 규격 밖 결과를 거른다.
- 연결 남음: FN-MYP-010-08·17 real 이미지 생성 클라이언트 (API·키 팀 결정, LJS)
- 연결 남음: FN-MYP-010-18 얼굴 영역 위치·샘플 10건 이상 검증 (real 생성기 결정 뒤, LJS)
- 연결 남음: Java `PythonCharacterGenerator` 연결 (LJS 백엔드)

## SCR-AIM-011 AI 대화창 (새 창) · 대화 저장·조회·삭제 — 끝
- 기능: FN-AIM-011-03 본창 세션 공유, FN-AIM-011-07 새 대화 생성, FN-AIM-011-08 반려동물 선택 · 펫 태그, FN-AIM-011-09 대화 목록 조회, FN-AIM-011-10 대화 선택 · 이어 쓰기, FN-AIM-011-11 대화 제목 자동 생성, FN-AIM-011-13 대화 삭제, FN-AIM-011-14 대화 이력 서버 저장, FN-AIM-011-19 이력 보관 · 파기
- 함께 만드는 것: `app/core` JWT 검증(HS256, 쿠키 `access_token`)·응답 껍데기·`X-Requested-With` 검사
- 기다리는 것: Python 전용 DB 계정 (LJS, 공용 DB에 직접 실행), LLM 제공자·키 (제목 생성 real 모드), 대화창 화면 (LJS 프론트, 연결 확인)
- 완료 조건: `AI_CNVRS_ROOM`·`AI_CNVRS_MSG`에 대화 생성·목록(펫 태그 필터)·조회·삭제가 되고, 탈퇴 회원 대화 파기 내부 API가 해당 회원 대화를 지운다. (DB 접속은 테스트에서 하지 않으므로 저장소 인터페이스 mock으로 검증)
- 연결 남음: FN-AIM-011-11 제목 생성 real 클라이언트 (LLM 제공자·키, LJS)
- 연결 남음: FN-AIM-011-14 공용 DB 실행 확인 (Python 전용 DB 계정, LJS)
- 해결: FN-AIM-011-03 로그아웃한 access 토큰이 통하던 문제는 인증 전환(Java 확인, 캐시 없음, 2026-10-26)으로 해결
- 연결 남음: FN-AIM-011-09·10 대화창 화면 연결 확인 (LJS 프론트)

## SCR-AIM-011 AI 대화창 (새 창) · 인증 전환 (Java 확인 호출) — 끝
- 기능: FN-AIM-011-03 본창 세션 공유 (2026-10-26 결정: JWT 직접 검증 → 요청마다 Java `/internal/auth/check`)
- 기다리는 것: 없음 (실제 Java 연결 확인 2026-10-26, 서버 간 키 양방향 제거)
- 완료 조건: `/ai/**`가 Java 확인 결과로 회원을 정하고, Java 인증 오류는 본문·`Set-Cookie`까지 그대로, Java에 닿지 못하면 502 `EXTERNAL_API_ERROR`. (Java는 가짜 응답으로 검증)
- 범위 밖: 대화 저장을 Java 내부 API로 옮기는 것(Java API 경로 미정), 탈퇴 파기 내부 API 삭제
